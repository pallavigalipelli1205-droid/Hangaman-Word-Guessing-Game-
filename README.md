# 🎮 Hangman Word Guessing Game

## 📌 Project Description
The Hangman Word Guessing Game is a Python-based interactive game developed using Streamlit. The main objective of the game is to guess the hidden word one letter at a time before running out of attempts.

This project provides a simple and user-friendly interface where users can register, log in, and enjoy playing the Hangman game.

## 🚀 Features
- User Registration
- User Login and Authentication
- Random Word Selection
- Interactive Gameplay
- Letter Guessing System
- Limited Attempts
- Win and Lose Conditions
- Simple and User-Friendly Interface

## 🛠️ Technologies Used
- Python
- Streamlit
- SQLite Database
- Git and GitHub

## 📂 Project Structure
- `app.py` – Main application file
- `auth.py` – User registration and login functionality
- `database.py` – Database connection and table creation
- `game_logic.py` – Game logic and word selection
- `requirements.txt` – Required Python libraries

## ⚙️ Installation and Setup

1. Clone the repository:

   ```bash
   git clone YOUR_GITHUB_REPOSITORY_URL
   ```

2. Open the project folder:

   ```bash
   cd Hangaman-Word-Guessing-Game-
   ```

3. Install the required packages:

   ```bash
   pip install -r requirements.txt
   ```

4. Run the application:

   ```bash
   streamlit run app.py
   ```

## 🎯 How to Play
1. Register with a username and password.
2. Log in to your account.
3. Start the Hangman game.
4. Guess the hidden word one letter at a time.
5. Win the game by guessing the complete word before your attempts run out.
